# Пять героев

Доступны только Бастион, Искра, Рута, Орион и Селена. Рута стала эпической по выбору владельца. Шансы осколков прежние. Старый профиль версии 5 переводится в версию 6 без сброса ресурсов, пройденных этапов и уровней оставшихся героев. Недостающие участники выдаются для полного отряда из пяти. Определения и рисунки снятых героев используются только для чтения старых записей боёв.

Селена и Рута получили отдельные части тела. Орион выполняет выпад с выносом руки и копья вперёд, мечи и парные клинки выполняют дуговой взмах. Посох Руты используется при магических атаках. Всем пяти доступно падение с движением суставов и сохранённым креплением оружия.
