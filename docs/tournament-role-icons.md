# Значки ролей в турнирах

Во всех турнирах используется общий `RoleIcon` и оригинальные изображения Dota 2.
Набор соответствует значкам макета LIGMA, описанным в чате «Уточнить работу с Figma».
Макет: https://www.figma.com/design/fL2GNyRUbr2rCzHHWUDkYh/LIGMA?node-id=4005-142

Источник файлов: установленная Dota 2, `game/dota/pak01_dir.vpk`, изображения Panorama.
PNG восстановлены Source2Viewer CLI 20.1 без перерисовки; на сайте используются
как маски, чтобы сохранять оригинальный силуэт и читаемость в обеих темах.
