# Публикация на основной сайт

По команде владельца от 8 ноября 2026 года выбранные шесть турниров переносятся
на основной сайт через `0201_publish_selected_archive_tournaments.sql`.
Это воспроизводимый исходный архив 0198 вместе с подтверждениями 0200, без
копирования тестовой базы. Рабочая база предварительно проверена чтением:
шесть адресов свободны, резервные номера не заняты, Sanraizu найден, совпадений
одного игрока у соперников нет. Исторические ники сохраняются.

Если 0198 уже применён на dev, новая публикация пропускает перенос данных,
чтобы сохранить последующие изменения владельца в тестовых турнирах.
