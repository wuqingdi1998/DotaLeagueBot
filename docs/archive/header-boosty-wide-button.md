# Архив широкой кнопки Boosty в шапке

До 3 октября 2026 года кнопка Boosty в верхней части сайта содержала значок и
текст `Boosty`. Её основные параметры: высота 52 px, горизонтальные отступы
17 px, промежуток между значком и текстом 8 px, оранжевая полупрозрачная заливка
и оранжевая рамка. При наведении кнопка полностью заливалась цветом `#f15f2c`,
а текст становился белым.

Широкий вариант убран из рабочего интерфейса. Этот файл сохраняет описание,
чтобы дизайн можно было восстановить без поиска старой версии проекта.
