# Архив старых лиг Discord-бота

Файлы `league.py` и `seasonal_league.py` сохранены как рабочая копия старых
инструментов обычной и сезонной лиг. Бот не загружает эту папку, поэтому старые
кнопки, окна, регистрация на турнир, распределение игроков, формирование лобби и
обмен с Google Таблицами сейчас не работают и не показываются в командах.

Связанные сервисы и библиотеки оставлены в проекте без удаления. Для возврата
старого варианта достаточно сначала проверить его на актуальной копии базы, а
затем перенести нужный файл обратно в `bot/cogs`.
