# Оригиналы персонажей

Для замены изображения положите сюда PNG с прозрачностью и именем игрового ID,
например `iskra.png`. Предпочтительно 1024–2048 пикселей, полный рост без обрезки.
Голова должна находиться около горизонтального центра изображения.

Сборщик `site/scripts/build-autobattler-assets.mjs` подготовит квадратную боевую
текстуру 256×256 и отдельный портрет до 768×768 из того же оригинала. Он не
увеличивает детализацию исходника искусственным растягиванием. Если отдельного
оригинала нет, используется исходный атлас; его координаты закреплены за ID в
`hero-visuals.json`, поэтому перестановка героев в каталоге не меняет их внешность.

Кадрирование лица, ритм, цвет и знак эффекта настраиваются в `hero-visuals.json`.
Новый герой требует отдельного оригинала и записи в игровом каталоге. Логика
боя и сохранённые ID не зависят от замены иллюстраций.
