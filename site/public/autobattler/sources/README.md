# Оригинальные иллюстрации героев

В этой папке лежат прозрачные изображения героев в полный рост — по одному WebP на игровой ID, например `iskra.webp`. Игровые ID, классы, способности и данные не зависят от файлов изображений.

Сборщик `site/scripts/build-autobattler-assets.mjs` проверяет прозрачность и подготавливает из каждого исходника боевую фигуру 512×512 и квадратный портрет. Портрет строится из верхней части исходника. Имена должны совпадать с каталогом героев. Фоны трёх глав и святилища находятся в `../environments/`.

Настройки ритма, цвета и визуального символа эффекта находятся в `hero-visuals.json`. Иллюстрации предназначены для 2D-сцен и не являются покадровой анимацией или 3D-моделями.
