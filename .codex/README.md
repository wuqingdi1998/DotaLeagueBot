# Правила Codex для этого проекта

Корневой [`AGENTS.md`](../AGENTS.md) требует от Codex перед любой работой читать
и соблюдать все отдельные правила из папки [`rules/`](rules/).

## Указатель правил

1. [`01-architecture.md`](rules/01-architecture.md) — модули, слои, зависимости
   и границы ответственности.
2. [`02-code-quality.md`](rules/02-code-quality.md) — размер файлов,
   самодокументируемый код и JSDoc.
3. [`03-reuse-and-data.md`](rules/03-reuse-and-data.md) — общие компоненты,
   отсутствие повторов и жёстко заданных значений.
4. [`04-styles.md`](rules/04-styles.md) — устройство CSS и мобильных стилей.
5. [`05-testing-and-refactoring.md`](rules/05-testing-and-refactoring.md) —
   фиксация поведения тестами и безопасный рефакторинг.
6. [`06-delivery.md`](rules/06-delivery.md) — сохранение изменений и штатная
   публикация без обходов.

Эти файлы являются обязательными требованиями проекта, а не рекомендациями.
