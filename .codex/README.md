# Правила Codex для этого проекта

Codex автоматически применяет постоянные правила проекта из корневого файла
[`AGENTS.md`](../AGENTS.md). Эта папка служит явным указателем на правила,
которые относятся к работе Codex.

## Публикация без обходов

1. Все завершённые изменения сохраняются в Git.
2. Все изменения отправляются в GitHub в ветку `main`.
3. Рабочий сайт обновляется только через
   [`.github/workflows/deploy.yml`](../.github/workflows/deploy.yml).
4. Нужно дождаться успешного завершения GitHub Actions и проверить публичный
   сайт.
5. Нельзя вручную копировать или редактировать файлы на сервере, вручную
   перезапускать рабочую систему вместо штатной публикации, пропускать проверки,
   использовать `--no-verify`, `force push` или временные обходные решения.
6. Если автоматическая публикация не прошла, причина исправляется в проекте,
   изменение снова сохраняется в Git и отправляется в GitHub.

Полный набор обязательных инструкций находится в [`AGENTS.md`](../AGENTS.md).
