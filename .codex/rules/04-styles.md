# Правило 04. Модульные стили

## Обязательная структура

- `site/app/globals.css` содержит только подключения модулей стилей.
- Стили хранятся в `site/app/styles/` и разделяются по пользовательским областям:
  основа сайта, шапка, страница турнира, управление турниром, список турниров,
  профиль и другие самостоятельные страницы.
- Один файл стилей обслуживает одну понятную область интерфейса.
- Файл CSS не должен превышать 500 строк.
- Мобильные правила элемента находятся в том же модуле, что и его основные
  стили, либо в явно названном общем адаптивном модуле, если правило относится к
  нескольким областям.
- Порядок подключений в `globals.css` считается частью поведения. Меняй его
  только после проверки влияния приоритетов CSS.

## Устойчивость

- Используй понятные классы, связанные с назначением элемента.
- Селектор не должен зависеть от случайного положения элемента в разметке.
- Используй общие переменные для повторяющихся цветов, отступов, размеров,
  радиусов и уровней наложения.
- Проверяй изменённый интерфейс на компьютере и телефоне.
- При переносе стилей сначала зафиксируй тестом порядок и состав подключений,
  чтобы рефакторинг не изменил внешний вид.

## Запрещено

- Возвращать все стили в один огромный файл.
- Исправлять старое правило длинной цепочкой более специфичных переопределений.
- Копировать одинаковые блоки CSS между страницами.
- Использовать `!important` как обычный способ решения конфликтов.
- Добавлять стили конкретного компонента в несвязанный модуль.
