# Правило 11. Autobattler LSE остаётся на dev до отдельного разрешения

- Autobattler LSE (Heroes Compendium) и все связанные изменения публикуются только на `dev.lsesports.ru` из `codex/dev`.
- Переносить игру или её обновления в `main` можно только по явной отдельной команде владельца о публикации Autobattler LSE. Общая команда «перенеси из dev», «пуш в main» или публикация другой возможности такого разрешения не даёт.
- Без такой команды оставляй на dev код игры, рисунки, шрифты, звуки, изменения базы, зависимости, настройки, документацию и относящиеся к игре части общих файлов. Не переноси всю `codex/dev` в `main` ради несвязанного обновления.
- Для другого обновления подготовь отдельный набор от текущего `main` и проверь состав отличий до отправки. После публикации перенеси этот набор из `main` в `codex/dev` с сохранением истории и опубликуй dev штатным процессом GitHub. Существующие изменения автобаттлера должны сохраниться.
- Пока в dev есть неопубликованные изменения автобаттлера, автоматическое обновление после `main` не должно заменять программу dev рабочей копией, стирать данные игры или её файлы. В этом случае обе версии могут намеренно отличаться: dev содержит опубликованные изменения сайта и дополнительный автобаттлер.
- Публикация `main` проверяет защищённые отличия до автоматического обновления dev. Если они есть, dev обновляется отдельной проверенной публикацией `codex/dev`, без сброса тестовой базы и файлов. Обязательные проверки обеих отправленных версий сохраняются.
- Перед окончательным отчётом проверь, что обновление основной задачи доступно на обоих сайтах, игра сохранилась на dev, а в составе обновления `main` нет изменений автобаттлера. Проверка выполняется без изменения рабочих данных.
