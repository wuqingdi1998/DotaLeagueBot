# Правило 02. Размер и качество кода

## Размер файлов

- Целевой и стандартный предел для написанных вручную файлов TypeScript, TSX,
  JavaScript и CSS — не более 500 строк.
- Не создавай новый файл больше 500 строк. При приближении к пределу раздели его
  по законченным обязанностям.
- Входной файл страницы обычно должен занимать не более 50 строк.
- Исключение допустимо только для автоматически созданного файла или случая,
  когда разделение разрушит целостность кода. Причина исключения должна быть
  явно описана и согласована с владельцем до добавления.
- Не дели файл на случайные фрагменты только ради счётчика строк. Каждый новый
  модуль должен иметь самостоятельную и понятную цель.

## Самодокументируемый код

- Имена файлов, функций, типов, переменных и свойств должны объяснять их смысл.
- Функция выполняет одно действие, имеет предсказуемый результат и не содержит
  скрытых побочных эффектов.
- Булевы значения называй с префиксом `is`, `has`, `can` или `should`.
- Избегай сокращений, смысл которых нельзя понять без знания истории проекта.
- Удаляй неиспользуемый код, временные обходы и закомментированные старые версии.
- Ошибки должны содержать полезный контекст, но не раскрывать секретные данные.

## Комментарии и JSDoc

- Структура и имена кода должны объяснять обычную логику без комментариев.
- Комментарий объясняет причину, ограничение или нестандартное правило, а не
  пересказывает строку кода.
- Добавляй JSDoc к публичной функции, хуку, сервису или сложному преобразованию,
  если назначение, входные данные, результат или важное ограничение нельзя
  однозначно выразить именами и типами.
- JSDoc должен оставаться коротким и актуальным. При изменении логики обновляй
  комментарий в том же изменении.

## Запрещено

- Оставлять функции с неясными именами вроде `handleData`, `doStuff`, `temp`.
- Скрывать сложность длинной функцией вместо выделения осмысленных операций.
- Добавлять комментарии, которые расходятся с фактическим поведением кода.
- Подавлять ошибки типов или проверок без объяснённой и согласованной причины.
